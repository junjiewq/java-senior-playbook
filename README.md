# 高级 Java · 可迁移能力白皮书

面向**高级 Java 外包开发者**的周末深度学习白皮书：并发与 JVM、Spring、数据一致性、MySQL/Redis、系统设计、架构决策、AI 提效，以及 P1/P2 补充主题。

强调：**可迁移能力**、架构判断、快速止血、面试亮点、AI 提效。

## 本地打开

双击打开本目录下的 [`index.html`](./index.html) 即可（需联网加载 Google Fonts / Mermaid / html2canvas CDN；正文与样式已内嵌）。

也可直接打开仓库外的同内容文件：

`高级Java外包-系统学习技术白皮书.html`

## GitHub Pages

若已启用 Pages（`main` 分支根目录），访问：

https://junjiewq.github.io/java-senior-playbook/

（以仓库 Settings → Pages 实际地址为准）

## 导出功能

页面顶部工具栏：

| 按钮 | 说明 |
|------|------|
| **导出 Markdown** | 下载 `.md`（含已填写的反思） |
| **复制 Markdown** | 复制到剪贴板 |
| **导出 PDF** | 调用系统打印，选择「存储为 PDF」 |
| **导出 Word** | 下载 `.doc`（HTML MIME） |
| 图表旁 **导出 PNG** | 将 Mermaid 图区域截图下载（需 html2canvas） |

## 反思框

各小节后的「我的反思与思考」为 `contenteditable`，自动写入浏览器 `localStorage`。导出时会带上已填写内容。

## 优先级目录（摘要）

- **P0**：并发与 JVM · Spring Boot/Cloud · 数据一致性 · MySQL · Redis · 可观测性 · 架构决策（何时不该拆）· AI for Senior Java
- **P1**：Kafka/RocketMQ · 网关/鉴权/零信任 · DDD 克制落地 · K8s · 性能工程
- **P2**：BFF/安全/合规 · 多数据源与批处理 · 职业策略与作品集

另含面试题库与 8 周周末路线。
