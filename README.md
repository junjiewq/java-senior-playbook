# 高级 Java · 可迁移能力白皮书

面向**高级 Java 外包开发者**的生产级深度学习白皮书：**深且好懂**——先人话与口诀，再原理、Runbook、故障模式与超详细面试答法。

覆盖：并发与 JVM、Spring Boot/Cloud、数据一致性、MySQL/Redis、可观测性与容量、架构决策、AI 生产向提效，以及 Kafka/网关/DDD/K8s/性能等 P1/P2 主题。

## 本地打开

打开 [`index.html`](./index.html)（需联网加载 Google Fonts / Mermaid / html2canvas CDN；正文与样式已内嵌）。

同内容中文文件名副本（仓库外父目录也可能有一份）：

`高级Java外包-系统学习技术白皮书.html`
