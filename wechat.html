入口 A

打开白皮书

下单正逆向闭环 · 交付冻结 v1.1 · GitHub Pages 静态页（无需后端）。

进入阅读 →
入口 B

打开对话机器人

Studio Agent（WebSocket）。微信内打开需公网 HTTPS + WSS，推荐带 ?embed=1 轻量壳。

进入对话 →
入口 B

对话机器人（待配置公网地址）

localhost 不能给微信用户用。先在本机启动 Studio + 隧道，再把 HTTPS 地址粘贴到下方。

配置 Studio 公网地址

优先级：URL 参数 ?studio= → 本机记住的地址 → assets/studio-config.js 里的 publicStudioUrl。

直接打开对话

完整 TXT 白皮书仍在仓库本地（未上 Pages）。语音/麦克风在微信内置浏览器可能受限，见下方说明。

公众号菜单怎么填

  • 自定义菜单 → 跳转网页 → URL 填：
    https://junjiewq.github.io/java-senior-playbook/wechat.html
  • 自动回复也可回同一链接；用户点开即进本合体页。
  • 这是H5 入口，不是在公众号会话气泡里直接聊 Agent。

两种「嵌入」别搞混

  • 方式 1（本页）：菜单/回复打开 HTTPS H5 → 白皮书 + 链到 Studio。可行，需公网 HTTPS/WSS。
  • 方式 2（真公众号消息会话）：用户在聊天列表跟公众号说话 → 需微信服务器回调、接入客服/消息 API，再转发到 Agent。不是 iframe，也不是改静态页就能完成。

限制与还缺什么

  • 微信不能打开 localhost / 局域网 HTTP；Studio 必须隧道或自有域名 HTTPS。
  • 对话依赖 WebSocket：页面 HTTPS 时用 wss://；隧道要同时转发 WS。
  • 麦克风 / 通话：需安全上下文；微信 WebView 对 getUserMedia、部分 TTS 支持不稳定，文字聊天最稳。
  • 本仓库未替你注册或配置微信公众号；菜单与域名校验需在微信公众平台自行完成。
  • 临时 trycloudflare 域名会变；对外长期用请绑稳定域名并改 studio-config.js。
